1. How Machine Learning Works Section 1.0

At its mathematical core, machine learning maps an input tensor space X ∈ ℝⁿ into a target label prediction vector ŷ. Through successive parameterized transformations in multi-layer architectures, neural weights and biases are iteratively refined using gradient descent algorithms.
